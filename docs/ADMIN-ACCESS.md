# 后台密码入口

登录后在“我的”点击“后台密码入口”，输入口令后由服务端验证；已有管理员直接进入工作台。输入框遮罩显示，离开页面即清空，客户端不保存口令或管理员权限。

## 目标数据库安装

1. 在现有 WorkBuddy Cloud PostgreSQL 管理控制台备份数据库函数与相关权限表。
2. 先执行 `sql/fix-order-support-workflows.sql`，再执行 `sql/restore-admin-password.sql`。
3. 使用普通登录账号验证错误口令被拒、正确口令进入工作台，以及新管理员权限可用。确认已认证接单员的身份与认证状态保留。

迁移包含本次指定口令的加盐 SHA-256 摘要，不在前端内置原始口令。验证要求已登录；每个账号 15 分钟内最多 5 次失败，成功操作记录审计。配置、失败次数及审计表禁止客户端直接访问。共享口令授权最高管理员，请仅交给受信任人员，并按需要轮换摘要。

本次没有目标库的管理连接，尚未在线执行迁移。前端修改和本地测试通过不代表线上口令已更改。

## 本地验证

`npm run check` 执行 UI 控制器回归及 PGlite 中的实际 SQL 测试，覆盖登录限制、正确和错误口令、限流、审计及角色保留。可通过临时环境变量 `CAMPUS_ADMIN_TEST_CODE` 验证指定口令与迁移摘要匹配；不要将口令写入项目配置或测试日志。

`npm run preview:web` 可在隔离浏览器适配器中操作“我的 → 后台密码入口 → 管理员工作台”。适配器不会给线上账号授权。
