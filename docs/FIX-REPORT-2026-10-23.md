## 客服问题对应结果

| 问题 | 处理结果 |
| --- | --- |
| 缓存旧高度导致发送后空白 | 保留整页滚动方案，渲染后先测量最新文档高度，再滚动；缺少测量 API 时仍可回退。 |
| 键盘与固定输入区冲突 | textarea 明确设置 `fixed`、`hold-keyboard`、`adjust-position=false`，监听键盘高度调整输入区位置与底部留白。仍需 iOS/Android 真机验证。 |
| 清空多行输入后留白未重测 | 发送清空后、行数变化后、键盘高度变化后重新测量输入区。 |
| 空气泡 | 过滤没有答案的 FAQ；流式空白保持“正在思考…”；最终空回答使用兜底并作为失败，不收取提问次数。 |
| 超时保护失效 | 独立定时器配合 `Promise.race`，覆盖配额预留及模型请求；无需 AbortController。超时、销毁后丢弃迟到结果与流式回调。底层请求取消仍取决于 SDK 支持。 |
| 失败消耗配额、本地计数可重置 | 配额改为服务端按账号和新加坡日期记账；调用前预留，成功计入，失败释放；失联预留 130 秒自动失效。详见下方限制。 |
| FAQ 单字误命中 | 单字不能直接命中；关键词至少两字，问题子串匹配也提高了具体度要求。 |
| 错误回复进入历史 | 跳过 `failed`、`pending` 和空白消息；重生成明确携带原问题。 |
| 重试重复欢迎语 | 只有空会话才添加欢迎语。 |
| 转人工标记截断 | 先给固定来源标记预留字符，再截取最近对话，正文不超过 500 字。 |
| 空会话工单 | 没有用户提问时阻止提交。 |
| 登录丢会话 | 按账号本地保存最近 100 条会话；登录跳转显式交接草稿并返回，交接有效期 30 分钟，普通会话保存 7 天。提供清空对话。 |
| 工单跟进不清楚 | 使用服务端返回的工单编号，显示“查看工单”直接入口。没有收到编号时不宣称提交成功。 |
| 运营文案 | 删除“来自后台配置的固定回答”等内部描述。 |
| 流式整数组更新 | 对消息字段使用路径更新，并节流流式渲染；新增消息时最多保留最近 100 条。 |
| 无反馈、无法重生成 | 增加有帮助、没帮助、重新生成；反馈通过受权限控制的 RPC 落库。 |
| 回答中点热门覆盖输入 | 检查 `sending` 后才修改输入。 |
| 输入长度提示不足 | 接近或达到 200 字时展示分条发送提示，超出部分被限制。 |

### 配额的边界

新增的配额账本不会因清理本地缓存或更换设备重置，正常客户端的失败调用会释放预留。但模型仍走现有 WorkBuddy 客户端直连通道，客户端可以被篡改、绕过预留或谎报失败。因此**这不是严格的模型成本防刷网关**。

要完成这部分严格防滥用，需要在可信服务端统一验证身份、执行限流、调用模型、提交成功状态，同时关闭可绕过的客户端直连模型权限。当前仓库没有该网关的部署环境或凭据，本次没有部署这部分基础设施，也没有声称已解决这一剩余风险。

核对目标库可使用以下只读查询（不要在日志中输出访问令牌或用户联系方式）：

```sql
SELECT p.oid::regprocedure, pg_get_functiondef(p.oid)
FROM pg_proc p JOIN pg_namespace n ON n.oid=p.pronamespace
WHERE n.nspname='public' AND p.proname IN
 ('list_my_orders','list_my_orders_v2','accept_order','abandon_order',
  'begin_support_ai','finish_support_ai','support_ai_usage','rate_support_answer');

SELECT tgname FROM pg_trigger
WHERE tgrelid='public.orders'::regclass AND NOT tgisinternal;
```
